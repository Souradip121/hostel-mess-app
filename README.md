# Hostel 7 Mess

> **This is a demo repo for [Blame](https://souradip121.github.io/blame/).** Team 7 (Riya, Arjun, Soham and Tisha) is made up, and so is this commit history: it was generated by `tools/make-demo-repo.mjs` in [Souradip121/blame](https://github.com/Souradip121/blame). The little app itself works.

A small web app for our hostel mess: today's menu, the whole week, star ratings for every meal and a complaints box.

## How to run

Open the folder with any static server, for example:

```
python -m http.server
```

Then open http://localhost:8000.
